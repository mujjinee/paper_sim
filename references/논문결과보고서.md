## 1. 서론



### 1.1 연구 배경



재생에너지(태양광) 발전사가 day-ahead 전력 시장에 참여할 때, 발전량 불확실성으로 인해 최적 commitment 결정이 어렵습니다. 기존 접근법은 **예측과 최적화를 분리**하여 처리함으로써, 최적화 결과가 예측 모델에 반영되지 못하는 한계가 있습니다.



논문의 저자는 이를 해결하기 위해 **예측 오차(nRMSE)와 optimality gap을 동시에 최소화**하는 "optimization-driven forecasting" 프레임워크를 제안합니다. 정규화 파라미터 W1/W2를 통해 예측 정확도와 운영 이익 사이의 트레이드오프를 조절할 수 있습니다.



### 1.2 기존 방식 vs 제안 방식



```

┌─────────────────────────────────────────────────────────────────────┐

│                    기존 방식 (Forecasting-First)                    │

├─────────────────────────────────────────────────────────────────────┤

│                                                                     │

│   ┌──────────────┐      ┌──────────────────┐                       │

│   │  AR / MLR    │─────→│  Unit Commitment  │                       │

│   │  (예측오차   │      │  (이익 최대화)    │                       │

│   │  최소화)     │      │                  │                       │

│   └──────────────┘      └──────────────────┘                       │

│         ↓                                            ↓              │

│   예측 → 최적화 일방향, 최적화 정보 예측 단계 미반영                │

│                                                                     │

├─────────────────────────────────────────────────────────────────────┤

│                  제안 방식 (Optimization-Driven)                    │

├─────────────────────────────────────────────────────────────────────┤

│                                                                     │

│   ┌──────────────────────────────────────────────┐                 │

│   │     통합 최적화 (MILP)                        │                 │

│   │                                              │                 │

│   │  min { W1 × [optimality gap]                │                 │

│   │      + W2 × [forecasting error] }            │                 │

│   │                                              │                 │

│   │  s.t. AR/MLR 제약 + Unit Commitment 제약     │                 │

│   └──────────────────────────────────────────────┘                 │

│         ↓                                                           │

│   예측과 최적화가 동시에 학습, W1/W2 비율로 트레이드오프 조절        │

│                                                                     │

└─────────────────────────────────────────────────────────────────────┘

```



### 1.3 핵심 평가지표



- **nRMSE (Normalized RMSE)**: 예측 정확도. 낮을수록 좋음.

- **Optimality Gap (%)**: `(오라클 이익 − 실제 이익) / 오라클 이익 × 100`. 낮을수록 좋음.

- **W1/W2**: 예측오차 가중(W2) vs optimality gap 가중(W1)의 비율

- **Penalty cost rate**: shortage 시 부과되는 벌금 비율. `PC = rate × DA`

## 2. 고민/고려/아이디어 도출에 대한 전체적인 의견



### 2.1 핵심 고민: Profit 함수의 구조



논문이 제시한 profit 함수(Eq. 1a)는 **3항**으로 표기됩니다:



```

profit = DA × x + RP × y⁺ − PC × y⁻     (논문 Eq. 1a)

```



하지만 shortage 발생 시, 모자란 전력을 real-time 시장에서 **사야 하는 비용(RP × shortage)**이 암묵적으로 포함되어야 한다는 점이 핵심 논의 사항이었습니다. 이에 따라 **4항** 식이 제안되었습니다:



```

profit = DA × x + RP × y⁺ − RP × y⁻ − PC × y⁻     (4항 수정안)

```



이 두 구조의 차이는 단순한 수식 수정이 아니라, 모델의 근본적인 방향성을 결정합니다. shortage 구간에서 3항 식은 `DA − PC > 0`이 항상 성립하므로 "커밋을 늘릴수록 무조건 이득"이라는 구조적 arbitrage가 발생합니다.



### 2.2 아이디어 도출 과정



3항 식의 arbitrage 문제를 해결하기 위해 다양한 접근법을 시도했습니다:



1. **Solver 변경**: 7개 solver(HiGHS, PuLP, cvxpy 계열)로 교차 검증 → solver 문제가 아님을 확인

2. **Penalty rate 스윕**: 0%~300%까지 테스트 → 패턴 불일치 확인

3. **오라클 구조 변경**: 2후보 → 3후보 oracle 비교 → 근본 문제 아님 확인

4. **새로운 접근**: shortage cost에 RP를 반영하는 4항 식 도입 → 논문 재현 성공

5. **Zhang 비대칭 3항**: c=1.0~3.0 스윕으로 이론적 타당성 검증

6. **방법 2 (PC=rate·(DA+RT))**: rate=0.1~1.0 스윕, 3항 구조 유지하면서 arbitrage 해소



### 2.3 전체적인 의견



> "논문이 실제로 보고한 수치 결과(Fig. 3, Fig. 5)를 만들어내는 구현은 4항 쪽이며, 이는 논문 원문 표기에 생략/암묵적 가정(RT 재구매 비용 포함)이 있을 가능성을 시사함."



3항 식은 문자 그대로의 표기이지만, penalty 정의(`PC = rate × DA`)와 결합하면 구조적 arbitrage가 발생하여 Fig. 3/Fig. 5 어느 것도 재현할 수 없습니다. 반면 4항 식은 penalty=50%에서 Fig. 3을 거의 정확히 재현했습니다(Gap 오차 ±0.1~1%p).

## 3. 시도 방법



총 6가지 주요 시도 방법을 비교했습니다.



### 3.1 시도 방법 요약



| 시도 | 방법명 | profit 함수 | 핵심 아이디어 | 재현 |

|------|--------|-------------|---------------|------|

| 1 | **4항식 (수정안)** | `DA·x + RP·y⁺ − RP·y⁻ − PC·y⁻` | shortage에 RP 재구매 비용 추가 | ✅ |

| 2 | **3항식 (논문 원문)** | `DA·x + RP·y⁺ − PC·y⁻` | 논문 Eq.1a 원문 그대로 | ❌ |

| 3 | **Zhang 비대칭 3항** | `DA·x + RP·y⁺ − c·RP·y⁻` (c=1.5) | shortage 가격에 상향조정 가중치 | ✅ |

| 4 | **방법 1: PC = rate·max(DA,RT)** | `DA·x + RP·y⁺ − rate·max(DA,RT)·y⁻` | 벌금 기준: max(DA,RT) | ❌ |

| 5 | **방법 2: PC = rate·(DA+RT)** | `DA·x + RP·y⁺ − rate·(DA+RT)·y⁻` | 벌금 기준: DA+RT 합계 | ✅ |

| 6 | **SPO+ loss** | Elmachtoub & Grigas (2022) | 의결손실 상한 최소화 | ❌ |

### 3.3 시도 2: 3항식 (논문 문자 그대로) — ❌ 재현 실패



**설명:** 논문 Eq. 1a를 문자 그대로 구현한 `DA·x + RP·y⁺ − PC·y⁻` 구조입니다. 7개 solver(HiGHS, PuLP CBC, cvxpy SCS/OSQP/CLARABEL, scipy L-BFGS-B/linprog/milp)로 교차 검증했습니다.



**성능 결과:**

- W1이 W2보다 커지는 순간(W1/W2 ≥ 2/1), 회귀계수가 `α=1.0, Σβ=0.0`으로 붕괴

- nRMSE가 116%까지 급증

- Gap이 음수(−30%대)로 계산됨



**문제점:**

- `PC = 0.5 × DA < DA`이므로 shortage 구간에서 `profit(x) = PC·a + (DA−PC)·x`가 x에 대해 항상 증가

- "무조건 최대 커밋(x=1.0)하라"는 구조적 arbitrage 존재

- 7개 solver가 동일한 전역 최적해에 도달 → solver 문제가 아님, 목적함수 구조 자체의 문제

- penalty rate을 0%~300%까지 스윕해도 Fig. 3/Fig. 5 패턴 재현 불가



### 3.4 시도 3: Zhang 비대칭 3항 (ρ₊ ≠ ρ₋) — ✅ 논문 재현 성공 (c=1.5)



**설명:** Zhang et al. (2024)의 전력시장 정산식을 차용한 접근법입니다. shortage 시 상향조정가격 `ρ₊ = c × RT`를 도입하여 3항 구조를 유지하면서도 arbitrage를 해소합니다.



```

profit = DA·x + RT·y⁺ − c·RT·y⁻

```



c를 스윕(c=1.0, 1.2, 1.5, 2.0, 3.0)하여 검증.

### 3.5 시도 4: 방법 1 (PC = rate·max(DA,RT)) — ❌ 재현 실패



**설명:** 벌금 기준을 `DA` 하나에서 `max(DA, RT)`로 변경하여, RT가 DA보다 비쌀 때 arbitrage를 해소하려는 접근법입니다.



```

PC = rate × max(DA, RT)

profit = DA·x + RP·y⁺ − PC·y⁻

```



**성능 결과 (block18):**

- nRMSE: **116.45%** 전체 W1/W2/rate 구간에서 동일

- Gap: 3~5%대 — 계수가 `x=1.0` (최대 커밋)으로 붕괴



**문제점:**

- block18에서는 method1이 완전 실패: 모든 조건에서 nRMSE=116.45%

- `max(DA, RT)`가 DA와 동일하거나 충분히 크지 않으면 arbitrage 해소 안됨

- block18 데이터에서 RT가 DA보다 낮은 경우가 많음



**업데이트:** 이전 보고서에서 "△ 부분 재현"으로 평가했으나, block18 전체 그리드(50조합) 실행 결과 **전체 구간에서 nRMSE=116.45%**로 나타나 재현 실패로 수정합니다.



### 3.6 시도 5: 방법 2 (PC = rate·(DA+RT)) — ✅ 논문 재현 성공 (rate=0.7)



**설명:** 벌금 기준을 `DA + RT` 합계로 변경하는 접근법입니다. RT 가격이 충분히 크면 arbitrage가 자연스럽게 해소됩니다.



```

PC = rate × (DA + RT)

profit = DA·x + RP·y⁺ − rate·(DA+RT)·y⁻

```



rate를 스윕(rate=0.1~1.0)하여 검증.

- penalty rate이 증가할수록 제안모형 Gap도 증가하지만 baseline Gap 증가폭보다 작음

- MLR 제안모형 nRMSE는 23~27%로 매우 안정적 — AR 대비 변동이 작음

- **핵심 통찰:** 외생형(MLR)이 내생형(AR)보다 penalty rate 변화에 덜 민감

## 5. 결론



### 5.1 주요 발견



1. **4항식(`−RP×shortage` 추가)이 가장 정확한 재현 제공**

   - Gap 오차 ±0.1~1%p로 논문 수치와 거의 일치

   - AR baseline Gap: 14.94% (논문 15.04%, ±0.1%p)

   - W1/W2=5/1에서 Gap: 11.50% (논문 11.38%, ±0.12%p)

   - MLR 제안모형: penalty rate 0~1.5% 구간에서 Gap이 baseline보다 일관되게 낮음



2. **Zhang 비대칭 방식(c=1.5)도 높은 재현 정확도**

   - Δ Gap=+0.28%p로 4항식(+0.63%p)보다 더 정확

   - 이론적 타당성: 전력시장 상향조정가격 구조 반영



3. **방법 2(PC=rate·(DA+RT), rate=0.7)도 성공 — 3항 구조 유지**

   - Δ Gap=−0.46%p로 논문과 거의 일치

   - 3항 구조를 유지하면서 arbitrage 해소 — 논문 원문에 가장 가까운 수정안



4. **3항식(논문 원문)과 방법 1(max(DA,RT))은 block18에서 재현 실패**

   - 3항식: arbitrage로 계수 붕괴 (nRMSE=86%)

   - 방법 1: 전체 구간에서 nRMSE=116.45% — arbitrage 해소 안됨



5. **SPO+ loss는 재현 실패**

   - baseline 대비 nRMSE/Gap 모두 개선 안됨

   - W1/W2가 증가하면 nRMSE가 100% 초과로 발산



6. **데이터 기간(90일)이 논문(300일)보다 짧아 nRMSE가 1~3%p 높게 나타남**



### 5.2 논문 통찰 재확인



- **예측 정확도 vs 운영 이익 트레이드오프:** W1/W2 조절로 제어 가능

- **Penalty rate 적응:** 제안 방법만이 penalty rate에 따라 commit 전략을 동적 조정

- **외생형(MLR) 우위:** 기상예보 데이터 활용 시 예측/최적화 성능 모두 우수

  - MLR은 penalty rate 변화에 덜 민감 (Gap 변동 9~13% vs AR 13~32%)

  - MLR은 W1/W2 스윕에서 nRMSE가 23~27%로 매우 안정적



### 5.3 한계



- MISO 가격 데이터 기간(90일)이 논문(300일)보다 짧음

- MISO 노드/기간이 논문에서 명확히 밝히지 않음

- nRMSE 절대값은 논문 대비 1~3%p 높게 나타남

- W1/W2 ≥ 5/1 구간에서 과적합 현상이 빠르게 발생

- SPO+는 block18이 아닌 block21에서 실험 — 직접 비교 불가

- 방법 1이 block18에서 완전히 실패한 이유(Data 분포 차이)가 불명확

## 6. 총평/감상평



### 6.1 이 논문의 가치



이 논문은 "예측-후-최적화" 패러다임의 한계를 정면으로 지적하고, **예측과 최적화를 통합한 단일 최적화 문제**로 재구성합니다. Decision-Focused Learning이라는 더 큰 연구 흐름의 초기 응용 사례로서, 다음과 같은 점에서 중요합니다:



1. **실용적 통찰:** "예측 정확도보다 이익 최대화가 더 중요하다"는 명제를 수치실험으로 입증

2. **조절 가능한 프레임워크:** W1/W2 비율로 트레이드오프를 사용자가 조절

3. **적응형 전략:** penalty cost rate 변화에 대응하는 동적 commit 전략



### 6.2 재현 과정에서 얻은 통찰



1. **수식 표기 vs 실제 구현의 간격:** 논문이 제시한 3항식은 문자 그대로 구현하면 arbitrage가 발생합니다. 저자가 실제로 사용한 구현은 4항식(또는 동등한 구조)이었을 가능성이 높습니다. 이는 학술 논문에서 자주 발생하는 "암묵적 가정 생략" 문제의 한 사례입니다.



2. **Solver 검증의 중요성:** 3항식의 문제를 solver 결함으로 오인할 수 있었습니다. 7개 solver로 교차 검증함으로써 "solver가 아니라 문제 구조 자체"임을 확인했습니다.



3. **데이터의 중요성:** 90일 학습 vs 300일 학습으로 인한 nRMSE 차이는 논문 재현에서 데이터 품질이 얼마나 중요한지를 보여줍니다. MISO 가격 데이터의 노드/기간 불명확성은 재현의 근본적 한계입니다.



4. **이론적 검증의 힘:** Zhang et al. 방식(ρ₊≠ρ₋)은 전력시장 정산 구조를 반영한 이론적 근거가 있어, 단순히 실험적으로 찾아낸 파라미터 조정보다 훨씬 신뢰도가 높습니다.



5. **다양한 profit 구조 비교:** 6가지 접근법을 체계적으로 비교한 결과, arbitrage 해소를 위한 "shortage cost 강화"가 핵심임을 확인했습니다. 4항식, Zhang(c=1.5), 방법2(rate=0.7)는 모두 shortage 비용을 충분히 크게 만들어 arbitrage를 해소합니다.



### 6.3 향후 방향



1. **MISO 가격 데이터 확장:** 2012.04~2014.07 전체 기간 확보 → 300일 학습 가능

2. **저자 문의:** MISO 노드/period, penalty 50% 선택 근거 확인

3. **비선형 모델 확장:** XGBoost/LSTM 등 딥러닝 모델과 최적화 통합

4. **ESS(에너지 저장장치) 결합:** 저장/방전 결정 변수 추가 → 현실적 시나리오

5. **리스크 회피(CVaR) 반영:** 기대값 최적화에서 리스크 고려 최적화로 확장

6. **방법 1 실패 원인 분석:** block18에서 max(DA,RT)가 arbitrage를 해소하지 못하는 구체적인 데이터 분석 필요
