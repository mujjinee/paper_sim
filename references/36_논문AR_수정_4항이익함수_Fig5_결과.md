# 36. 논문AR_수정.py(4항 이익함수) Fig.5 데이터 및 원문 불일치 확인

## 배경

`논문AR_수정.py`(사용자가 별도로 만든 파일, `references/논문AR_정리.md`도
함께 존재)는 이익함수를 다음과 같이 "수정"해서 쓴다:

```
realized = DA·x + RP·y⁺ − RP·y⁻ − PC·y⁻     (shortage_cost = RP + PC)
```

이 파일은 W1/W2 스윕(Fig.3용)만 있었고, 이번에 **PENALTY_RATE
0~100% 스윕(Fig.5용)** 버전을 `temp_논문AR_수정_fig5데이터추출.py`로
새로 만들어 데이터를 뽑았다.

## 원문 Eq.(1a)와의 불일치

이 "수정판" 공식은 이 세션 초반에 PDF 원문(7페이지)을 직접 렌더링해
검증했던 논문 Eq.(1a)와 다르다. 그때 확인한 원문은 **3항**뿐이었다:

```
DP·x + RP·y' − PC·y''     (원문 Eq.1a, 3항)
```

`-RP·y''`(부족분에서 RT가격만큼 추가로 깎는 항)는 원문에 없다. 오히려
이 4항짜리 버전은 `run_simulation.py`/`run_experiment_comparison.py`가
쓰던 것을 세션 초반에 **버그로 판정해서 3항으로 통일**했던 것과
동일한 형태다(`15_블록9_AR_MLR_재현_실험_정리.md` §2 참고).

## 그런데도 왜 이 "틀린" 공식이 더 안정적으로 보이는가 — 가설

- shortage_cost가 `PC` 대신 `RP + PC`가 되면서, 부족(shortage) 1단위당
  비용이 커진다 — 이는 곧 §1(18/27번 문서)에서 도출한 "약정>S가 이득"이
  되는 조건 `DA > PC` 대신 `DA > RP + PC`로 바뀐다는 뜻이다. `RP`가
  추가되면서 이 부등식이 성립하기 더 어려워지므로(우변이 커짐),
  **과대약정이 유리해지는 조건 자체가 원래보다 훨씬 드물게 발생**한다.
  이게 발산이 사라진 이유로 보인다.
- 즉 "수정판"은 우연히 안정적인 게 아니라, **부족비용을 원문보다 더
  무겁게 매겨서 §1의 발산 조건을 구조적으로 완화**시킨 것 — 27번
  문서의 B-2(벌금율 100% 재설계) 아이디어와 같은 방향의 효과를,
  다른 방식(항을 하나 더함)으로 얻은 셈이다.
- 다만 이건 **논문을 재현한 게 아니라 논문과 다른 모형을 푼 것**이라는
  점은 분명히 해야 한다 — 안정성과 원문 충실도는 트레이드오프 관계다.

## 결론

| 질문 | 답 |
|---|---|
| 이 공식이 원문 Eq.1a와 같은가? | 아니다. 원문은 3항, 이 파일은 4항(`-RP·y''` 추가) |
| 사용자가 이전에 준 Fig.3 표의 출처는? | 이 파일(`논문AR_수정.py`)로 확인됨(50% 지점 수치 완전 일치) |
| 발산이 없는 이유는? | 부족비용이 `PC`가 아니라 `RP+PC`로 커져, 과대약정 유리 조건이 구조적으로 완화됨(18/27번 문서 메커니즘의 다른 해법) |
| 이 결과를 논문 재현으로 써도 되는가? | 주의 필요 — 원문 충실도보다 안정성을 택한 "다른 모형"이라는 점을 밝히고 써야 함 |
