## Abstract 핵심

- 기존 "forecasting-first optimization-second" 방식은 예측과 최적화가 분리되어

  예측이 최적화 결과(profit)에 미치는 영향을 반영하지 못함.

- 제안: 예측 오차와 optimality gap을 동시에 최소화하는

  "optimization-driven forecasting" — day-ahead unit commitment 최적화 모델을

  regression 학습 과정에 통합.

- AR(내생적), MLR(외생적) 두 회귀모델 기반으로 검증. 제안 모델이 예측 정확도를

  크게 희생하지 않으면서 profit을 개선함을 수치실험으로 입증.



## 문제 배경 (Day-ahead commitment)

- Day-ahead 시장: 다음날 시간대별 공급 커밋 발표. Real-time 시장: 실제-커밋 간

  차이 보정.

- 재생에너지(태양광/풍력)는 연료비 없어 price-taker로 행동 -> 얼마를 커밋할지가

  핵심 결정.

- Day-ahead 가격이 real-time보다 평균적으로 높음 -> 가능한 많이 day-ahead에

  커밋하는 것이 유리하나, 부족분(shortage) 발생 시 penalty cost 부과.



## 제안 모델 구조

- 전통 방식(Fig.2a): 회귀로 예측 -> 예측치를 optimization model의 파라미터로

  주입 -> day-ahead commitment 결정. 학습 단계에서 optimization 정보 미반영.

- 제안 방식(Fig.2b): 회귀 손실함수 + unit commitment 목적함수를 통합한 하나의

  최적화 문제로 회귀 계수를 학습 -> 예측오차와 optimality gap을 동시 최소화.



### Unit commitment base model (Eq. 1a-1g)

- 목적함수: day-ahead commitment profit + real-time trading 기대이익 - shortage

  penalty cost.

- 결정변수: day-ahead commitment(E_t), surplus/shortage(변수), mismatch 변수.

- 파라미터: day-ahead price, real-time price(확률), penalty cost, 실제 재생

  에너지 생성량, 예측 생성량.



### Forecasting 모델

- **AR (endogenous)**: 과거 p시간 데이터로 선형 예측, direct multi-step

  방식으로 24시간(야간 제외 12시간)에 대해 별도 계수셋 학습, loss = 절대오차합.

- **MLR (exogenous)**: 기상예보 등 외부 독립변수(12개, 이후 backward stepwise로

  SSRD, TSR, Hour 3개 선택) 기반 선형회귀, loss = 절대오차합.



### 제안 optimization-driven forecasting (Eq. 9, 10)

- AR 버전(Eq.9): AR 절대오차 손실 + unit commitment 모델을 결합, 목적함수에

  regularization 파라미터 λ1(예측오차 가중), λ2(optimality gap 가중) 도입.

  λ1=1,λ2=0 이면 순수 AR과 동일.

- MLR 버전(Eq.10): 동일한 구조로 MLR 손실 + unit commitment 결합.

- λ2/λ1 비율을 높이면 optimality gap 최소화 쪽으로, forecasting error는 다소

  증가하는 trade-off.



## 수치실험 (Section 5)

- 데이터: GEFCom2014 태양광 데이터(호주), MISO day-ahead/real-time 가격.

  Train 300일 / Test 100일(본문 실험 설계 기준; 5.2/5.3절에는 3개월 train,

  1개월 test 서술도 있음 — 원문 자체에 두 설명이 혼재).

  야간 제외, 하루 12시간(09:00~21:00)만 사용.

- 평가지표: nRMSE(예측오차), optimality gap(%) = (제안모델 결정으로 얻은 목적함숫값

  대비 실제값 기반 최적해의 차이).

- Penalty cost rate: day-ahead price의 0%~100% 사이 11단계로 실험.



### Endogenous(AR) 결과 (Table 3, penalty=50%)

- AR: nRMSE 34.76%, optimality gap 15.04%.

- 제안모델(λ1=1, λ2=20): nRMSE 34.89%, gap 13.91% — 정확도 거의 유지하며 gap 개선.

- λ2 비중을 낮출수록(λ1 비중↑) gap은 더 줄지만 nRMSE 악화

  (예: λ1=1,λ2=0 → nRMSE 50.07%, gap 11.36%).

- penalty rate 0~100% 스윕(Fig.5): AR은 nRMSE 불변(예측만 최적화하므로),

  제안모델은 penalty rate에 따라 커밋량을 조정 → gap이 상대적으로 일정하게 유지.



### Exogenous(MLR) 결과 (Table 4, penalty=50%)

- MLR: nRMSE 21.76%, gap 12.59%.

- 제안모델(λ1=1, λ2=2): nRMSE 21.66%, gap 10.65% — 정확도 개선 + gap 개선(양쪽 다 좋아짐).

- 전반적으로 exogenous 접근(MLR)이 endogenous(AR)보다 예측/최적화 성능 모두 우수.



### 결론 (Section 6)

- 제안 방법이 기존 대비 optimality gap을 최대 endogenous 4%p, exogenous 3%p

  감소. 예측 정확도를 크게 해치지 않으면서 profit 개선 가능함을 확인.

- Regularization 파라미터(λ1, λ2)와 penalty cost rate에 따라 모델을 튜닝 가능

  — 이는 기존 decoupled 방식에서는 불가능한 유연성.

- 본 연구는 pilot study 성격, future work 언급(원문 마지막 문단이 잘림).
