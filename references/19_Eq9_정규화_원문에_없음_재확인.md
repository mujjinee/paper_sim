# 19. Eq.(9a) 정규화(denom) 원문에 없음 — 재확인 및 문헌 검토

## 배경

`18_z03_블록18_제안모형_W1W2_발산_분석.md`에서 W1/W2=1/1 부근 발산의 수학적
조건을 도출했으나, 그 유도는 코드(`denom_h` 정규화 포함)를 기준으로 한
것이었다. 사용자 질문("Eq.(9) 정규화 공식을 다시 확인해달라, 관련 문헌도
검토해달라")에 따라 PDF 원문을 다시 정밀 대조하고 관련 문헌을 조사했다.

## 1. 원문 재확인 (PDF 6페이지, PyMuPDF 6배 확대 렌더링)

Eq.(9a) 원문:

```
min Z^h = Σ_{t∈U_h} ( W1( DP_t·S_t − (DP_t·x̂_t + RP_t·y'_t − PC_t·y''_t) )
                       + W2|S_t − x̂_t| )

s.t.  y_t = S_t − x̂_t                         (9b)
      y_t = y'_t − y''_t                        (9c)
      y'_t ≤ S_t                                (9d)
      α^h, β_l^h unrestricted                    (9e,9f)
      y'_t, y''_t ≥ 0                            (9g)
```

(x̂_t = α^h + Σ_l β_l^h S_{t-h-l}, Eq.10a도 MLR 버전으로 구조 동일)

**확인 결과: `denom_h`(오라클 합으로 나누는 정규화)도, `scale=CAPACITY_MW×
DURATION_HOURS`도 원문 어디에도 없다.** W1 항은 달러 단위 손실(regret),
W2 항은 0~1 비율 단위 절대오차(MAE) — 서로 다른 물리 단위의 두 항을
정수 비율(1,2,5,10,20)로 섞는데, **이를 같은 스케일로 맞추는 방법에
대한 언급이 원문에 전혀 없다.** 이는 논문 자체의 서술 공백이다.

## 2. 우리 프로젝트 자체 기록에서 발견한 사실

`15_블록9_AR_MLR_재현_실험_정리.md` §5 (이미 이 세션 초반에 작성됨):

> "학습 목적함수의 정규화 분모(오라클 합)는 `operational_corrected` 원래
> 방식({0,S,capacity})을... 쓰도록 분리했다 — **평가용 오라클을 학습에도
> 그대로 쓰면 W1=1,W2=20의 의도된 균형이 깨져 계수가 발산(AR nRMSE 103%까지
> 치솟음)하는 걸 실제로 확인했기 때문**"

즉 `denom_h` 정규화는 **논문을 그대로(또는 논문에 더 가깝게) 구현하려다
발산해서, 외부 프로젝트 `operational_corrected`의 임시방편을 빌려온 패치**
였다는 사실이 이미 이 세션 초반 작업 기록에 남아 있었다. **18번 문서에서
분석한 W1/W2=1/1 발산은 논문의 순수 수식이 아니라, 이 패치의 성질을 관찰한
것**이라는 게 이번 재검증으로 명확해졌다. 패치를 걷어내고 더 논문에
가까운 정규화(평가용 오라클 {0,S})를 그대로 학습에 썼을 때는 논문의
"정상" 비교점(W1=1,W2=20)에서조차 이미 발산(nRMSE 103%)했다는 기록이
남아있다 — 즉 패치 자체가 없으면 상황은 더 나빴다.

## 3. 관련 문헌 검토

Semantic Scholar 기준 이 논문(DOI 10.1016/j.apenergy.2022.119929)을 인용한
15편 중, Eq.(9)의 W1/W2 정규화 방식을 직접 재현·비판한 논문은 발견하지
못했다. 다만 같은 "가치지향(value-oriented)/decision-focused 재생에너지
예측" 분야의 후속 연구들은 대체로 다른 접근을 취한다:

- **Deriving Loss Function for Value-oriented Renewable Energy Forecasting**
  (arXiv:2310.00571) — 경제손실과 예측오차를 **이층 최적화(bilevel
  program)**의 KKT 조건으로부터 **직접 유도**해 구간별 선형(piecewise-linear)
  손실함수를 얻는다. W1/W2 같은 임의 가중치가 없다.
- **Value-Oriented Forecast Combinations for Unit Commitment**
  (arXiv:2503.13677), **Toward Value-oriented Renewable Energy Forecasting**
  (arXiv:2309.00803) — 마찬가지로 원 최적화 문제 구조에서 손실을 유도하는
  방향, 임의 가중합 방식을 쓰지 않음.

즉 이 분야의 더 엄밀한 후속 연구들은 **"$ 단위 항 + 비율 단위 항을 정수
가중치로 그냥 섞는" Eq.(9a) 같은 방식을 채택하지 않는다** — 정확히 우리가
겪은 스케일 불일치 문제를 구조적으로 피하는 방향(bilevel/KKT 유도)으로
발전했다는 정황이다. Karimi & Kwon(2022)의 Eq.(9a) 방식이 사후적으로 보면
다소 임시방편적(ad-hoc)이었을 가능성을 뒷받침한다.

## 4. 결론

| 질문 | 답 |
|---|---|
| Eq.(9a)에 정규화(denom) 공식이 있는가? | **없다.** W1(regret, $ 단위) + W2(MAE, 비율 단위)를 그대로 더할 뿐 |
| `denom_h` 정규화는 어디서 왔는가? | 논문이 아니라 외부 프로젝트 `operational_corrected`의 임시방편(이미 15번 문서에 기록되어 있었음) |
| 왜 이 패치가 필요했는가? | 패치 없이(더 논문에 가까운 오라클을 학습에 그대로 써도) 논문의 "정상" 비교점(W1=1,W2=20)에서 이미 발산했기 때문 |
| 18번 문서의 발산 분석은 무효한가? | 아니다 — 정확히는 "논문 수식"이 아니라 "논문을 풀리게 만드는 이미 알려진 패치"의 성질을 분석한 것으로 재해석해야 한다 |
| 관련 문헌은 이 문제를 어떻게 다루는가? | 같은 분야 후속 연구들은 임의 가중합 대신 bilevel/KKT 유도 손실함수로 이 스케일 불일치 자체를 피해간다 |
| 최종 판단 | Eq.(9a)는 W1/W2 스케일 정규화 방법을 명시하지 않은 **논문 자체의 서술 공백**이며, 우리가 겪은 발산은 이 공백을 메우려던 어떤 정규화 방식을 택하든 구조적으로 나타나는 현상으로 판단됨 |
