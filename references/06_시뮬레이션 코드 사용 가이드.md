





# 시뮬레이션 코드 사용 가이드



## 파일

- `04_Simulation_Code.py` — 전체 시뮬레이션 코드



## 실행 방법



```bash

# 기본 실행

python 04_Simulation_Code.py --data data.csv --output output



# 특정 penalty rate만 테스트

python 04_Simulation_Code.py --data data.csv --penalty-rates 0.3 0.5 0.7



# 특정 W 비율만 테스트

python 04_Simulation_Code.py --data data.csv --W-ratios 1 1 5 1 10 1

```



## 데이터 형식 (data.csv)



| timestamp | solar_power | da_price | rt_price | tcw | sp | ... |

|-----------|-------------|----------|----------|-----|---------|-----|

| 2013-01-01 09:00 | 15.2 | 45.3 | 42.1 | 0.3 | 1013 | ... |

| 2013-01-01 10:00 | 22.8 | 48.7 | 46.5 | 0.2 | 1012 | ... |



- `solar_power`: MW 단위 (코드에서 30MW로 정규화)

- `da_price`, `rt_price`: $/MWh 단위

- 나머지 열: 기상 변수 (MLR용, 없으면 AR만 실행)



## 출력



```

output/

├── ar_results.csv              # AR 모델 결과

├── proposed_results.csv        # 제안 모델 결과

└── comparison_results.png      # 비교 그래프 (Fig. 3, Fig. 5 스타일)

```



## 주요 클래스/함수



| 이름 | 설명 |

|------|------|

| `AutoRegressiveModel` | 기존 AR 예측 모델 |

| `MultipleLinearRegression` | 기존 MLR 예측 모델 |

| `optimization_driven_ar()` | 제안 방법 (내생형) |

| `optimization_driven_mlr()` | 제안 방법 (외생형) |

| `calculate_nrmse()` | 정규화 RMSE 계산 |

| `calculate_optimality_gap()` | 최적성 갭 계산 |
