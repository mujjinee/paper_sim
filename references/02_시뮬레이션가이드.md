## 2. 시뮬레이션 흐름



```

[Training Phase]

  ↓

Historical Data → Regression Model 학습 (AR or MLR)

  ↓

[Prediction Phase]

  ↓

Regression Model → Next-day Solar Forecast (Ŝ_t)

  ↓

[Optimization Phase]

  ↓

Forecast + Price → Day-ahead Commitment (x_t) 결정

  ↓

[Evaluation]

  ↓

nRMSE (예측 오차) + Optimality Gap (이익 손실) 계산

```



---



## 3. 핵심 수학 모델



### 3.1 최적화 모델 (Day-ahead Unit Commitment)



```

max Σ (DP_t · x_t + RP_t · y⁺_t - RP_t · y⁻_t - PC_t · y⁻_t)



subject to:

  y_t = S_t - x_t          (mismatch 정의)

  y_t = y⁺_t - y⁻_t        (surplus/shortage 분해)

  y⁺_t ≤ S_t               (surplus 상한)

  y⁻_t ≤ x_t               (shortage 상한)

  x_t ≥ 0, y⁺_t ≥ 0, y⁻_t ≥ 0

```



**변수 설명:**

- x_t: Day-ahead commitment (결정변수)

- S_t: 실제 발전량 (확률변수)

- y⁺_t: Surplus (발생량 > commitment)

- y⁻_t: Shortage (발생량 < commitment)

- DP_t: Day-ahead 가격

- RP_t: Real-time 가격

- PC_t: Penalty cost ( shortage 시 부과)



### 3.2 고전적 접근 (Forecasting-First)



```

Step 1: AR/MLR로 Ŝ_t 예측 (오차 최소화만)

Step 2: Ŝ_t를 최적화 모델에 대입 → x_t 결정

```



### 3.3 제안 방법 (Optimization-Driven)



```

min Σ { W₁ · [optimality gap] + W₂ · [forecasting error] }



subject to:

  Ŝ_t = α + Σ β_h · S_{t-h}  (AR model constraints)

  y_t = S_t - x_t

  y_t = y⁺_t - y⁻_t

  x_t ≥ 0, y⁺_t ≥ 0, y⁻_t ≥ 0

```

```python
import numpy as np

import pandas as pd

from scipy.optimize import minimize

from sklearn.linear_model import LinearRegression

import matplotlib.pyplot as plt



# 1. 데이터 로드

solar_data = pd.read_csv('solar_power.csv')      # 시간별 발전량

prices = pd.read_csv('day_ahead_real_time.csv')   # 가격 데이터



# 2. AR 모델 (고전적 접근)

def ar_forecast(solar_data, n_lags=12):

    """Auto-regressive forecast"""

    X, y = [], []

    for t in range(n_lags, len(solar_data)):

        X.append(solar_data[t-n_lags:t])

        y.append(solar_data[t])

    X, y = np.array(X), np.array(y)



    model = LinearRegression()

    model.fit(X, y)



    # 다음 날 예측

    last_n = solar_data[-n_lags:]

    forecast = []

    for h in range(24):

        pred = model.intercept_ + model.coef_ @ last_n[-n_lags:]

        forecast.append(pred)

        last_n = np.append(last_n[1:], pred)

    return np.array(forecast)



# 3. 최적화 모델 (day-ahead commitment)

def unit_commitment(forecast, dp_prices, rp_prices, penalty_rate=0.5):

    """Day-ahead unit commitment problem"""

    n = len(forecast)

    pc = penalty_rate * dp_prices  # penalty cost



    # Objective: max profit

    def objective(x):

        y = forecast - x  # mismatch

        y_plus = np.maximum(y, 0)

        y_minus = np.maximum(-y, 0)

        profit = np.sum(dp_prices * x + rp_prices * y_plus - rp_prices * y_minus - pc * y_minus)

        return -profit  # minimize negative profit



    bounds = [(0, None) for _ in range(n)]

    result = minimize(objective, forecast, bounds=bounds, method='L-BFGS-B')

    return result.x



# 4. 제안 방법 (Optimization-Driven Forecasting)

def optimization_driven_forecast(solar_train, dp_train, rp_train, n_lags=12, W1=1, W2=1):

    """Integrated optimization-driven forecasting"""

    def integrated_objective(params):

        alpha = params[0]

        betas = params[1:n_lags+1]



        # Forecast

        forecast = np.zeros(24)

        for h in range(24):

            forecast[h] = alpha + np.dot(betas, solar_train[-n_lags:])



        # Optimization (commitment)

        pc = 0.5 * dp_train[-24:]

        def commitment_obj(x):

            y = forecast - x

            y_plus = np.maximum(y, 0)

            y_minus = np.maximum(-y, 0)

            return -np.sum(dp_train[-24:] * x + rp_train[-24:] * y_plus - pc * y_minus)



        result = minimize(commitment_obj, forecast, bounds=[(0, None)]*24, method='L-BFGS-B')

        x_opt = result.x



        # Optimality gap + forecasting error

        actual = solar_train[-24:]

        optimality_gap = -result.fun

        forecast_error = np.sum(np.abs(forecast - actual))



        return W1 * optimality_gap + W2 * forecast_error



    # Solve

    result = minimize(integrated_objective, np.zeros(n_lags+1), method='L-BFGS-B')

    alpha_opt = result.x[0]

    betas_opt = result.x[1:n_lags+1]



    # Final forecast

    final_forecast = alpha_opt + np.dot(betas_opt, solar_train[-n_lags:])

    return final_forecast, result.x



# 5. 평가 지표

def nrmse(actual, predicted):

    rmse = np.sqrt(np.mean((actual - predicted)**2))

    return 100 * rmse / np.mean(actual)



def optimality_gap(actual, dp, rp, penalty_rate=0.5):

    pc = penalty_rate * dp

    max_profit = np.sum(np.maximum(dp, rp) * actual)

    actual_profit = np.sum(dp * actual + rp * np.maximum(actual - dp, 0) - pc * np.maximum(dp - actual, 0))

    return 100 * (max_profit - actual_profit) / max_profit

```
