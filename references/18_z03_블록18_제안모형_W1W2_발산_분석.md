# 18. z03/블록18 제안모형 W1/W2 발산 분석

## 배경

`z03_블록18_Fig1_3_4_5_비교분석.py`로 논문 Fig.3(W1/W2 스윕)을 z03/블록18(학습
2013-08-25~2013-11-22, 테스트 2013-11-23~2013-12-22)에서 재현한 결과, W1/W2=1/1을
넘어서면서 nRMSE가 68%→116%로 급격히 발산하고 2/1 이상에서는 116.45%에 고정되는
현상이 발견되었다. 논문(Table 3)은 같은 격자에서 34.76%→50.07%로 완만하게 증가한다.

## 원인: 목적함수 자체가 극단값을 선호 (경계조건 도출)

제안모형 MILP(Eq.9)의 목적함수를 x(약정량)에 대해 미분하면, 약정이 실제발전량 S를
넘어서는 구간(x>S, 부족 발생)에서:

```
d(목적함수)/dx = W2/n − 0.5·W1·scale·DA_i / denom_h     (penalty=50% 대입)
```

이 값이 음수이면 목적함수는 x를 키울수록 계속 줄어들어, 최적화가 x를 상한(1.0,
설비 정격용량)까지 밀어붙인다. 정리하면:

```
발산 조건:  W1/W2  >  2·denom_h / (n·scale·DA_i)
```

z03/블록18에서 이 임계값은 약 1.3~1.8 수준으로 실측되었고, 논문 Table 3의 W1/W2
격자(…,1/1, 2/1, 5/1,…)가 정확히 이 지점을 가로지른다.

**중요**: denom_h(학습 오라클 합)와 n(학습일수)은 함께 비례해서 커지므로, 학습
기간을 90일→300일로 늘려도 이 임계값 자체는 거의 변하지 않는다. 원인은 기간
길이가 아니라 이 4개월 구간(2013년 늦여름~겨울, Zone3) 고유의 DA/RT/발전량
조합에 있다.

## bounded LAD와의 관계: 무관함

| | bounded LAD (기본 모형) | 이 발산 (제안모형) |
|---|---|---|
| 메커니즘 | 학습 중 `Xβ∈[0,1]` 제약이 적합 자체를 왜곡 | 이익함수가 극단값을 선호, `x≤1`은 이를 막는 안전장치일 뿐 |
| 껐을 때 결과 | 다른(때로 더 나은) 해가 나옴 | MILP가 무한발산(해 없음) — 이전 유계조건 감사에서 증명됨 |
| W1/W2 의존성 | 없음 (기본 모형엔 W1/W2 자체가 없음) | 전적으로 W1/W2가 원인 |

두 현상은 표면적으로 같은 `[0,1]` 경계를 공유하지만, 하나는 "학습을 왜곡하는
제약"이고 다른 하나는 "발산을 막는 안전장치"로 정반대 역할을 한다. 무관.

## 결론 및 조치 (옵션 ① 채택)

- 이 발산은 코드 결함이 아니라 **논문 수식(Eq.9)이 갖는, 데이터 의존적 안정성
  경계**를 z03/블록18이 실제로 드러낸 것이다. 상보조건·유계조건은 여전히 정확히
  구현되어 있다(기존 감사 결론 유지).
- 논문이 실제로 사용한 비교점(W1=1, W2=20)은 이 임계값(~1.3~1.8)보다 한참 작은
  안전 구간에 있으며, 여기서는 재현 결과(36.29%)가 논문(34.89%)과 여전히 근접한다.
- 따라서 **W1≥W2 구간은 "논문이 검증하지 않은 영역 밖"으로 명시**하고, 발산
  자체를 투명하게 보고하는 쪽으로 결론 — 별도의 정규화 보정(denom 하한 등)은
  적용하지 않는다.
