## 3. 원인



2후보 oracle은 문제의 표면일 뿐:



- 3항 식 자체에 **`DA−PC > 0`**라는 구조적 arbitrage가 있음 — shortage 구간에서

  `profit(x) = PC·a + (DA−PC)·x`이고 x를 키울수록 무조건 이득.

- oracle을 3후보든 2후보든 어떻게 설정하든 이 방향성 자체는 바뀌지 않음.

- 오라클 크기만 바뀌면서 gap 계산이 더 나빠질 뿐.

## 5. 3항 식을 정상화할 수 있는 다른 방법들



### 방법 1: 벌금률 정의를 `PC = rate·max(DA, RT)`로 변경 (Zhang et al. 2024 영감)



| 구분 | 식 |

| --- | --- |

| 지금 | `PC = rate·DA` → `PC < DA`가 항상 성립 → arbitrage 발생 |

| 변경 | `PC = rate·max(DA, RT)` |



- `DA=40, RT=60`: `PC = 0.5×60 = 30` → 아직 `PC < DA` (부족)

- `DA=40, RT=90`: `PC = 0.5×90 = 45` → `PC > DA` ✓ (arbitrage 사라짐)



**결론**: RT가 DA보다 비쌀 때만 arbitrage가 사라지고, RT가 싸면 여전히 arbitrage가 남음. 완전한 해결 아님.



---



### 방법 2: 벌금률 정의를 `PC = rate·(DA + RT)`로 변경



| 구분 | 식 (DA=40일 때) |

| --- | --- |

| 지금 | `PC = 0.5·DA = 20` |

| 변경 | `PC = 0.5·(DA + RT)` |



- `DA=40, RT=60`: `PC = 50 > DA` ✓

- `DA=40, RT=10`: `PC = 25 < DA` → 여전히 arbitrage 남음



**결론**: RT가 충분히 크면 arbitrage 사라지지만, RT가 DA보다 훨씬 쌀 때 여전히 문제. 완전한 해결 아님.



---



### 방법 3: Zhang et al. 방식 — ρ₊ ≠ ρ₋ 비대칭 시장가격 모델 채택 (가장 이론적으로 타당)



지금 3항 식은 shortage cost를 PC 하나로만 표현. Zhang 논문 정산식:



```text

profit = DA·x + ρ₋·surplus − ρ₊·shortage

```



- `ρ₊` (부족 시 상향조정가격) ≠ `ρ₋` (초과 시 하향조정가격)

- 전력시장에서 `ρ₊ > DA > ρ₋`가 항상 성립

- `DA − ρ₊ < 0` → arbitrage가 아예 발생하지 않음



**문제**: MISO 데이터에는 ρ₊/ρ₋ 분리 없음, DA/RT만 있음.



**대안**: `ρ₋ = RT`로 두고 `ρ₊ = c·RT` (`c > 1`, 예: `c=1.5`)로 근사 → Zhang 방식과 구조적으로 동일한 3항 식 만들 수 있음.



**결론**: 이 방식이 가장 이론적으로 타당. MISO 데이터에서 `c` 값을 실험적으로 검증 → c=1.5에서 논문 재현 성공(Δ nRMSE=+0.8%p, Δ Gap=+0.3%p). 실제 실행 결과는 아래 섹션 6.2 참조.



---



### 방법 4: Smart SPO+ loss (Elmachtoub & Grigas 2022)



- W1/W2 혼합 대신 SPO+ loss로 변경

- Piecewise-linear 구조로 shortage/surplus 방향을 구분해서 다르게 페널티

- Dual-based decision error 측정 (|oracle − realized| 아님)



**결론**: 구현 복잡하고, 근본적인 `DA − PC > 0` 문제 자체를 바꾸진 않음. 보조적 접근 가능.



---



### 방법 5: 학습용 오라클 분모를 2후보 `max(DA·S, RT·S)`로 고정



- 지금 학습 오라클: `{0, actual, 1.0}` 3후보

- Paper Eq.(9a) 분모: `max(DP·S, RP·S)` — 2후보

- 맞추면 objective coefficient 스케일이 달라져 계수 붕괴가 늦어질 수 있음



**결론**: W1이 충분히 크면 결국 붕괴 — 근본 해결 아님. (실제 실행 결과는 아래 참조)

### 6.1 방법 4 (SPO+ loss) 실행 결과



#### 변경 내용



기존 W1/W2 혼합 방식(`min W1×gap + W2×|e|`)을 SPO+ loss로 완전히 교체:



```text

min  W1 × Σζ_i/n + W2 × Σ|e|_i/n

s.t. ζ_i ≥ max{profit_k} − realized_profit_i   (k = {0, actual, 1.0})

```



- `ζ_i`는 의결손실(oracle − realized)의 상한

- 기존 방식이 gap을 사후 계산한 것과 달리, SPO+는 학습 자체를 gap 상한 최소화로

- `x_i = Xβ`로 직접 연결 (기존 `e_i` 분리 변수 제거)

## 7. 결론



**4항(`-RP*shortage` 추가)이 가장 정확한 재현을 제공하지만, Zhang et al. 방식(ρ₊=c·RT, c=1.5)도 3항 구조를 유지하면서 논문 재현에 성공함.**



방법 4(SPO+)는 Gap 음수 문제를 일부 개선했지만(+17~21%), nRMSE 53~69%로 논문과 완전히 다름.

방법 3(Zhang ρ₊≠ρ₋)은 c=1.5에서 W1/W2=1/20: nRMSE=35.68%(논문 34.89%), Gap=14.19%(논문 13.91%)로 재현 성공.



shortage cost를 `PC` 하나만 쓰는 게 아니라 `RP+PC`로 만들면 shortage 구간 profit의

기울기가 `DA − (RP+PC)`가 되고, RT가격이 DP보다 비싸질 수 있으므로 이 부호는

샘플마다 달라짐 → over/under 커밋 양쪽이 모두 비용이 되고 계수 붕괴가 자연스럽게

없어짐(이미 `논문_제안_모형_AR_z03_블록18_수정.py`에서 Gap ±0.1~1%p로 검증됨).



3항 식(논문 Eq.1a 문자 그대로)은 arbitrage 구조가 수식 자체에 내장되어 있어, solver

종류, oracle 정의, penalty rate, 상한 제약, regularization 손잡이 등 어떤 방법으로

조정하더라도 Fig.3/Fig.5를 재현할 수 없다. 논문 저자가 실제로 쓴 수식은 4항이거나,

최소한 shortage side에 `RT` 가격을 반영한 버전일 가능성이 매우 높다.
